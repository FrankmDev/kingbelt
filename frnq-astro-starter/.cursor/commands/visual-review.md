# Visual review

1. Open the real local site with the browser tools available in the current environment.
2. Inspect mobile, tablet when layout changes, and desktop.
3. Compare observable output with `docs/project/DESIGN.md` and the page plan.
4. Do not edit on the first pass.
5. Classify issues as blocking, high, medium, or low.
6. For each issue, cite evidence, viewport, and exact files likely to change.
7. Propose the smallest correction scope and the exact files to modify.
