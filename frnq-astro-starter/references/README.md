# Visual references

Add screenshots, image files, PDFs, or short reference notes here before project initialization. Create `references.json` from `references.example.json` and describe the exact role of each file.

Rules:

- One reference may guide composition without guiding color or branding.
- `useFor` is an allow-list; `doNotUseFor` is an explicit exclusion.
- Use relative filenames inside this directory.
- Do not add credentials, private customer data, or unlicensed assets intended for production.
- References guide principles. They are never copied wholesale.
- The initializing agent must inspect every declared file and record the principle extracted from it in `docs/project/DESIGN.md`.
